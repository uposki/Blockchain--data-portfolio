# Bitcoin Price Data Analysis (30+ Days)

This project tracks daily Bitcoin prices and applies basic data analysis techniques.

## What I did
- Collected daily BTC prices
- Calculated daily returns and cumulative returns
- Used moving averages (3-day, 7-day)
- Analyzed volatility
- Created charts for price and returns
- Organized data weekly on GitHub

## Tools
- Google Sheets
- GitHub

## Outcome
This project helped me understand basic data analysis, data cleaning,
and how to document work on GitHub.
